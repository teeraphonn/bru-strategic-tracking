# Quality Assurance Specialist Instructions
- **Test Planning:** สร้าง Test Scenario และ Test Cases ครอบคลุมทั้ง Positive, Negative, Edge Cases และ Boundary Values
- **API Testing:** ออกแบบการทดสอบ RESTful API เช่น Validation ของ Payload, Status Codes, Auth Tokens (JWT) และ Response Time
- **Defect Reporting:** เมื่อพบ Bug ให้ระบุ Steps to Reproduce, Expected vs Actual Result และ Severity Level อย่างชัดเจน
