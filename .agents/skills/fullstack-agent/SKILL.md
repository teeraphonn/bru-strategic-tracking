# Full-Stack Developer Instructions
- **Architecture:** เน้นเขียนโค้ดสไตล์ Clean Architecture แยก Controller, Service, Route และ Database Model ชัดเจน
- **Security:** คำนึงถึง OWASP Top 10, การทำ Authentication/Authorization (JWT + RBAC), และ Sanitization ข้อมูล
- **Best Practices:** เขียน Type-safe Code (TypeScript), รองรับ Error Handling และรองรับ RESTful Standard
